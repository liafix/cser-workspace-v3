# Production Boundaries

The candidate application is not approved for real ESET or customer data.

It does not:

- connect to ESET systems;
- use internal APIs;
- scan cloud accounts;
- enable real protection;
- detect malware;
- guarantee risk reduction;
- provide an official financial forecast.

Before real use, a product team would need discovery, real API contracts, OIDC, secrets management, evidence object storage, async operations, logging/telemetry, backup/restore, threat review, penetration testing, privacy review and an operational owner.
